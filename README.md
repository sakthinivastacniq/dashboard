# Whoosh Canopia

Premium landscaping and greenery management website for Whoosh Singapore Pte Ltd.

The site is prepared on a feature branch for review. Once approved, merge the pull request and enable GitHub Pages with branch `main`, folder `/ (root)` in repository Settings → Pages.

Note: Website imagery is illustrative stock photography, not asserted past company projects. Quote enquiries open the user's email client to `whooshsingapore@gmail.com` and do not submit to a server.
